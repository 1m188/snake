# snake_web

纯静态网页版贪吃蛇，复刻本仓库各终端版本的游戏逻辑，无需任何构建工具。

## 运行方式

- 直接双击 `index.html` 在浏览器中打开；或
- 在本目录运行 `python -m http.server 8000`，访问 <http://localhost:8000>。

## 操作

- 移动：`WASD` / 方向键；触屏设备支持画布滑动手势与虚拟方向键。
- 空格 / 回车 / 画布轻点：开始、暂停 / 继续、结束后重新开始。
- `ESC`：在结束界面返回开始界面。

## 游戏规则

- 蛇初始 3 节，位于场地中央、向右移动。
- 吃到食物 +1 分并增长一节，食物在随机空位重新生成。
- 蛇头撞到边界（墙）或自己的身体即游戏结束。
- 随分数逐渐加速：每吃 3 个食物，移动间隔减 1 逻辑帧（60FPS 逻辑帧率，间隔 10 → 2 帧，初始约 150ms/格）。
- 历史最高分保存在浏览器 localStorage 中。

## 测试

核心逻辑（蛇、食物、游戏状态机、最高分存储）不依赖 DOM，可用 Node 直接运行冒烟测试；另有无头装配测试在 vm 沙箱中按页面脚本顺序加载全部模块，模拟按键与帧推进做端到端验证：

```
node test/logic.test.js
node test/storage.test.js
node test/browser.wiring.test.js
```

## 项目结构

```
snake_web/
├── index.html        # 页面结构与脚本加载顺序
├── css/
│   └── style.css     # 现代简洁风格样式、响应式与触屏控件
├── js/
│   ├── constants.js  # 场地尺寸、速度参数、方向与状态枚举等常量
│   ├── snake.js      # 蛇实体：移动、转向（180° 防反）、碰撞检测
│   ├── food.js       # 食物生成（保证不落在蛇身上）
│   ├── game.js       # 游戏状态机、60FPS 逻辑帧循环与加速曲线
│   ├── storage.js    # 历史最高分 localStorage 读写（含降级处理）
│   ├── render.js     # Canvas 渲染：棋盘、蛇、食物、朝向眼睛
│   ├── input.js      # 键盘 + 触屏（滑动 / 虚拟方向键）输入翻译
│   └── main.js       # 入口装配：主循环、状态切换、覆盖层与分数 DOM
└── test/
    ├── logic.test.js         # 核心逻辑冒烟测试
    ├── storage.test.js       # 最高分存储冒烟测试
    └── browser.wiring.test.js # 无头装配集成测试（vm 沙箱模拟浏览器）
```

## 实现说明

- 逻辑帧与渲染解耦：`requestAnimationFrame` 驱动渲染，游戏内部按固定
  60FPS 逻辑帧率推进（按真实时间累积），与显示器刷新率无关。
- 方向输入缓冲：同一移动间隔内的多次按键取最后一个，移动帧时应用并做
  180° 防反，与仓库其他版本行为一致。
- 各 JS 模块采用 IIFE + 命名空间模式：浏览器中以传统 `<script>` 按依赖
  顺序加载（兼容 `file://` 直接打开），Node 中通过 `module.exports` 供测试。
